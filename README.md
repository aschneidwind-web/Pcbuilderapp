# PC Builder (static web app)

This is a single-file HTML app (no build step).

## Run it

### Option A: open the file directly

Open `pc-builder/index.html` in your browser.

### Option B: run a local server (recommended)

From PowerShell (Node.js required):

```powershell
cd "C:\Users\Andrew\Documents\pc-builder"
npx --yes serve@latest . -l 5173
```

Then open `http://localhost:5173` in your browser.
